# Setup checks

Read `CONTRIBUTING.md` and the relevant module before changing setup behavior.

Use the pinned Node.js and pnpm versions. Run focused checks with real temporary files and processes. For interface changes, inspect the rendered page.

Report the actual commands and results. Keep local configuration, credentials, and generated logs outside the source tree. Close the development processes created for the task.
