# 卡片恢复既有 Task：界面与请求边界

日期：2026-10-28。此增量依赖 Task resume 后端，以及已冻结的消息卡片和文件时间握手包。它不修改后端、持久 Snapshot、Task revision、任务活动时间或业务生命周期。

## 用户行为

卡片对话区显示当前入口与所展示 Task 的关联。未关联或关联其它 Task 时，用户可明确点击“恢复此任务”。成功只确认关联已保存；“让 GPT 继续”仍需另一次点击。恢复不会自动发送宿主消息、创建 Task 或宣称模型已读。

卡片调用入口与宿主随后唤起的模型入口可能不同。界面只陈述本次可验证入口的关联；继续请求由后端生成，要求模型先检查并在必要时明确恢复同一个 Task，再读取原工作区恢复信息。

宿主没有提供可验证入口时，卡片不生成或猜测入口标识。只有宿主支持消息能力才显示“请 GPT 恢复此任务”；此按钮明确请求模型执行 inspect/resume，成功回执仅表示宿主接受请求。宿主也不支持消息时，只显示当前限制与手动请求方式。

## 状态与并发

`qm_session` 的 `_meta.quaymesh.task_binding` 单独保存到 CardState；即使 `unchanged:true` 也更新，不依赖 Task revision。缺失、目标不符或形状非法时清空旧关联能力；业务快照及活动时间保持原含义。已知 closed 状态继续阻止恢复和继续。

source 为绑定读取分配请求顺序。晚到的旧回包不能覆盖较新请求。显式 inspect/resume 进行期间，文件分页仍能返回页面内容，但其 sideband 不获得覆盖这次显式操作的权限，避免“恢复先发、分页随后”读到提交前状态后盖回成功回执。

主 controller 在显式关联操作期间暂停其既有刷新调度，完成后恢复原调度。没有新增网络 timer。隐藏、终态、首包完整性协商及最多三次首次失败限制保留。

| 情形 | 行为 |
| --- | --- |
| 恢复成功 | 保存响应中的关联，清除本次待确认请求，提示尚未请求 GPT 继续 |
| 超时、断连或回执异常 | 保留 `request_key` 和原 `expected_binding_revision`；明确重试沿用同一输入 |
| 关联版本冲突／旧回执已被替代 | 清除已被明确拒绝的请求，要求重新检查；不自动换版本重发 |
| 冲突后后台读取变为 selected | 仍不能绕过检查直接继续；显式 inspect 成功后才解除检查要求 |
| 缺少入口身份 | 不调用猜测的恢复；仅在用户点击时请求宿主模型核对 |
| 卡片销毁 | 取消本卡片请求；晚到响应不能更新界面或声明成功 |

恢复工具只提交显式 Task 参数，不注入兼容 `session_id`／`member_id`。服务端仍负责 OAuth owner、client、入口身份、Task 权限、CAS 与幂等；UI 不替代这些检查。

## 界面细节

当前关联、恢复结果和错误提示通过安全文本节点显示。消息草稿与输入节点不因绑定刷新被替换，因此焦点和选区保留。继续按钮使用当前后端 binding 能力，避免持久快照同 revision 的旧 `capabilities.continue` 抵消已经完成的恢复。未支持新绑定接口的静态／预览 source 保留原能力路径。

新增动作沿用现有 `ib` 按钮和设计变量。窄屏动作换行排布，按钮标签保持整行文字；长 Task 标识可换行，不增加横向溢出。

## 验证

新增纯测试覆盖：保存后丢回执的同 key/revision 重试、CAS 冲突后的显式检查、缺入口与关闭 Task、unchanged 绑定更新、隐藏时无新增绑定请求、销毁后晚到回包，以及被替代回执不能借后台 selected 绕过检查。

source 合同测试覆盖：首次文件时间协商保持、unchanged sideband、缺失／非法字段清空、Task 身份验证、取消、旧 poll 与新恢复、恢复期间分页先后到达、adapter 前缀错误码以及宿主能力分支。

真实浏览器测试使用原 OAuth 与 MCP 服务，只在测试宿主选择不同或缺失的外部入口元数据。覆盖跨入口恢复同一 Task、Task revision/活动不变、草稿焦点、真实提交后丢回执、真实 CAS 竞争、宿主降级、动作可见性和 430 px 布局。没有伪造 Task 状态或绕过生产授权。

本地只有转译与纯 controller 环境，不能据此声称真实 SDK、原生 SQLite 或浏览器已经通过。主控需执行原生 typecheck、上述 source/controller 测试、构建及 `task-resume-card.spec.ts`，并与现有消息、生命周期、旧卡片兼容回归一并核对。
