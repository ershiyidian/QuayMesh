# 执行占用与恢复

[English](EXECUTION-OWNERSHIP-RECOVERY.md) · 简体中文

状态：后续版本设计。2026-10-30 的小补丁已补齐代理任务归属、跨节点代理编号和工具范围说明；本文中的单条占用恢复尚未实现。

## 问题与目标

本次现场中，游戏工程可以正常读取，用户指定的 C 盘日志也已通过现有 shell 接口读取并复制到项目诊断目录。两个旧命令占用分别属于其他项目。排查还确认：代理创建占用时遗漏任务归属，跨节点错误又丢失代理编号，调用端因而难以找到可处理的对象。

更长期的问题是历史执行结果、实际进程活动和资源占用的恢复分散在多处。清理一个旧操作经常被拖入整节点维护流程。目标是让普通查看持续可用，让单个异常执行可以独立恢复，让任务和节点状态保持真实。

## 复用现有三层关系

| 对象 | 职责 | 结束依据 |
| --- | --- | --- |
| Task | 用户目标、上下文、消息和结果归属 | 用户目标完成或明确终止 |
| 具体执行 | 一条命令或代理的一轮运行 | 对应进程及其受管后代结束，或提供方确认该轮结束 |
| 资源占用 | 协调此次执行实际修改的文件和目录 | 所属具体执行释放资源 |

继续使用 WorkLedger、console_operations、console_executions、execution_owners 和现有执行协调器。代理占用应关联本轮 console_executions.id；命令继续关联 console_operations.id。Task 归属由现有 qm_run_links 查询。启动代理的请求回执和代理运行本身有不同的结束时刻，恢复时沿实际执行记录查找。

## 一、集中处理真实执行结束

ProcessSessionManager 已能在进程组结束后释放占用，并保留结果待确认记录；维护状态也已有物理结束记录。将这些现有能力收敛为共用的执行收尾逻辑：

- 命令及其受管后代均已退出：保存退出信息，释放对应占用。
- 请求超时但执行仍运行：继续跟踪同一次执行，原调用可按操作编号取回输出。
- 执行已经结束但返回结果缺失：保留结果待确认记录，释放已结束执行占用的资源。
- 任务关闭或归档：处理任务记录；正在运行的执行由明确的取消操作结束。

占用的存活检查复用已有 PID、启动时间和执行代次。将只检查 PID 是否存在的路径改为同一身份检查，避免复用后的 PID 被误认为原执行。

## 二、提供单条占用恢复

在现有 workspace_context recovery 和控制台恢复操作中支持定位 claim_id，共用一段恢复逻辑：

1. 读取这一把锁关联的具体执行、所属任务、节点和资源。
2. 核对该执行当前是否仍运行。
3. 已结束则释放这一把锁；仍运行且用户要求停止则调用现有取消命令或中断代理入口。
4. 以实际停止结果完成释放，返回该操作的处理结果。

其他项目继续运行。节点离线时保留该节点的恢复状态，其他在线节点继续服务。历史记录字段缺失时，从 agent、run 和已有执行关系补齐可查到的身份；恢复不依赖任务标题猜测。

## 三、保持读取与修改的合理范围

readWorkspace 已采用无文件锁的普通查看，继续沿用。结构化修改继续按文件占用；长期命令按实际项目声明 execution_scope；需要独立修改同一仓库的工作沿用现有 worktree。

稳定文件复制继续使用现有单文件传输与一致性检查。对于持续增长的日志，先在源端生成本次读取的诊断副本，再传输副本，避免网络传输期间长期占用原文件。

导出根约束结构化工作区与文件接口。execution_scope 负责命令的并发调度，实际 shell 文件访问遵循本机账户权限。用户已授权的外部日志可通过 shell 读取，需要结构化查看时复制到指定诊断目录。

## 四、拒绝结果能够直接处理

冲突结果应携带所在节点、claim_id、具体执行身份、可获得的 Task 身份、受影响资源和对应的查询/取消入口。代理错误始终保留 agent_id。控制台从同一记录显示任务名称与执行状态，工具和界面共用判断。

目录范围错误应给出可用目录和下一步操作。连接错误、任务目标状态、执行活动和文件占用分别使用已有事实，避免把同一历史异常同时展示为多种正在运行或阻塞状态。

## 实施顺序与验收

先统一真实执行收尾，再提供单条恢复，再统一进程身份与界面展示。当前小补丁独立提交，便于先进入发行包。

验收使用真实文件、数据库和进程，覆盖四个会影响使用的场景：

- 同一工程有执行任务时，仍能读取当前文件和日志。
- 请求超时后进程正常退出，对应资源自动释放，原始结果状态保留。
- Core 重启后，结束的旧执行可以独立恢复，其他仍运行执行保持原进程。
- 代理启动回执已经返回、代理仍在运行时，占用保持；本轮代理结束后释放。
