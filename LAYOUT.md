# Source layout

[Architecture](docs/ARCHITECTURE.md) describes component responsibilities. [Contributing](CONTRIBUTING.md) covers source builds and the development environment.

| Directory | Contents |
| --- | --- |
| `node/` | Node configuration, lifecycle, installation, and networking |
| `src/` | MCP, execution, providers, persistence, and interface |
| `apps/` | Platform applications |
| `test/` | Integration and browser tests |
| `scripts/` | Build, development, and maintenance commands |
| `schema/` | JSON and database definitions |
| `examples/` | Public configuration examples |
| `docs/` | English and Simplified Chinese guides |
| `third_party/` | Component sources and license texts |
